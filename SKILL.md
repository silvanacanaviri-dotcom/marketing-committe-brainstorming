# MARKETING COMMITTEE BRAINSTORMING

## 1. PROPÓSITO

Este Skill analiza y estructura la información obtenida durante el Comité de Marketing mensual.

Su función principal es determinar qué decidió realmente el Comité de Marketing para el mes correspondiente y transformar esa decisión en una instrucción estratégica clara para el Monthly Content Planner.

Este Skill no tiene como objetivo simplemente resumir una reunión.

Debe:

- identificar el objetivo mensual;
- detectar nuevas decisiones estratégicas;
- analizar discusiones y desacuerdos;
- identificar la última decisión válida;
- distinguir opiniones de decisiones;
- detectar cambios de opinión;
- detectar aceptación, concesión y consenso;
- identificar prioridades;
- identificar necesidades de comunicación;
- identificar ideas;
- identificar eventos;
- identificar fechas;
- identificar materiales necesarios;
- identificar tareas;
- identificar temas pendientes;
- comparar las decisiones del comité con el objetivo base del Monthly Content Planner;
- determinar si existe una nueva orden estratégica mensual;
- solicitar confirmación humana cuando corresponda;
- generar una ORDEN ESTRATÉGICA MENSUAL DEL COMITÉ.

---

# 2. POSICIÓN DENTRO DEL SISTEMA

La arquitectura general es:

COMITÉ DE MARKETING
↓
MARKETING COMMITTEE BRAINSTORMING
↓
ORDEN ESTRATÉGICA MENSUAL DEL COMITÉ
↓
MONTHLY CONTENT PLANNER
↓
CREACIÓN DE CONTENIDO

Este Skill representa la etapa de análisis estratégico.

El Monthly Content Planner representa la etapa de planificación.

El Skill de Creación de Contenido representa la etapa de producción.

Cada Skill debe conservar su función.

---

# 3. OBJETIVO BASE Y ORDEN MENSUAL

El Monthly Content Planner puede tener objetivos estratégicos base o permanentes.

Por ejemplo:

- dirigirse a gerentes y directores;
- aumentar el alcance;
- aumentar seguidores;
- fortalecer posicionamiento;
- llegar a tomadores de decisión.

Estos objetivos no deben considerarse eliminados simplemente porque el Comité haya hablado de otro tema.

El Comité puede generar una nueva prioridad u objetivo específico para un determinado mes.

Por ello deben diferenciarse:

### OBJETIVO BASE

Es la orientación estratégica que el Monthly Content Planner mantiene como referencia general.

### ORDEN ESTRATÉGICA MENSUAL

Es una nueva instrucción confirmada por el Comité para un mes específico.

Cuando exista una Orden Estratégica Mensual confirmada, esta tendrá prioridad durante el mes indicado sobre el objetivo base que resulte incompatible con ella.

El objetivo base no debe considerarse eliminado permanentemente.

---

# 4. FUENTES DE INFORMACIÓN

El Skill puede utilizar:

1. Granola.
2. Miro.
3. Información del Monthly Content Planner.
4. Información adicional proporcionada por el usuario.

---

# 5. GRANOLA

Granola constituye la fuente principal para analizar la reunión.

Granola puede proporcionar información relacionada con:

- objetivo mensual principal;
- requerimientos;
- decisiones;
- ideas;
- tareas;
- fechas de eventos;
- observaciones;
- prioridades;
- sugerencias.

El Skill debe utilizar esta información como primera capa de análisis.

No debe duplicar innecesariamente el trabajo realizado por Granola.

---

# 6. REVISIÓN DE LA REUNIÓN COMPLETA

Cuando el resumen de Granola sea suficiente, puede utilizarse directamente.

Sin embargo, el Skill debe analizar la reunión completa cuando existan:

- contradicciones;
- discusiones;
- desacuerdos;
- diferentes propuestas;
- cambios de opinión;
- decisiones contradictorias;
- falta de claridad;
- posibles acuerdos;
- aceptación;
- concesiones;
- cambios posteriores;
- falta de cierre.

La reunión completa debe utilizarse para reconstruir el contexto.

Nunca debe tomarse una decisión estratégica basándose únicamente en una frase aislada cuando exista una discusión relacionada.

---

# 7. MIRO

Miro funciona como fuente complementaria.

Puede utilizarse para identificar:

- ideas;
- prioridades;
- campañas;
- temas;
- propuestas;
- agrupaciones;
- contenidos;
- relaciones entre ideas.

Cuando Granola y Miro presenten información contradictoria, el Skill debe señalar la discrepancia.

No debe inventar una decisión para resolver la contradicción.

---

# 8. FRECUENCIA DEL COMITÉ

El Comité de Marketing se realiza normalmente durante la primera semana de cada mes.

La fecha puede variar.

No existe un día fijo obligatorio.

El Skill debe identificar el mes correspondiente a partir de la reunión o de la información proporcionada.

---

# 9. FRECUENCIA DE PUBLICACIONES

La frecuencia de publicaciones pertenece al Monthly Content Planner.

Este Skill NO debe modificar automáticamente la frecuencia de publicaciones.

Si durante el Comité se habla de una frecuencia diferente, debe clasificarse como:

- sugerencia;
- requerimiento;
- decisión;
- decisión pendiente.

Una mención aislada no modifica automáticamente la frecuencia establecida en el Monthly Content Planner.

---

# 10. IDENTIFICACIÓN DEL OBJETIVO MENSUAL

El Skill debe determinar cuál es el objetivo estratégico que el Comité decidió para el mes.

Debe diferenciar entre:

- objetivo base;
- objetivo propuesto;
- objetivo discutido;
- objetivo modificado;
- objetivo confirmado;
- objetivo rechazado;
- objetivo pendiente.

No debe considerar una propuesta como objetivo confirmado hasta que exista suficiente evidencia de una decisión.

---

# 11. ANÁLISIS DE DISCUSIONES

Cuando dos o más participantes tengan opiniones diferentes, el Skill debe analizar toda la evolución de la conversación.

Debe identificar:

1. Qué propuso cada participante.
2. Qué argumentos presentó.
3. Qué objeciones surgieron.
4. Qué alternativas fueron planteadas.
5. Si alguien cambió de opinión.
6. Si alguien aceptó el argumento de otra persona.
7. Si alguien cedió.
8. Si hubo consenso.
9. Si hubo una decisión explícita.
10. Si hubo una decisión implícita suficientemente clara.
11. Si posteriormente la decisión cambió.
12. Cuál fue la última decisión válida.

---

# 12. RESOLUCIÓN DE DESACUERDOS

El Skill NO debe elegir automáticamente:

- la primera propuesta;
- la última propuesta;
- la propuesta más repetida;
- la opinión de la persona con mayor autoridad;
- la opinión expresada con mayor intensidad.

Debe determinar cuál fue la opción con la que finalmente quedó el Comité.

---

# 13. ACEPTACIÓN Y CAMBIO DE OPINIÓN

El Skill debe detectar expresiones que indiquen:

- aceptación;
- concesión;
- consenso;
- cambio de opinión;
- aprobación.

Ejemplos:

- "Sí, tienes razón."
- "De acuerdo."
- "Bueno, vamos con esa."
- "Está bien."
- "Sí, hagámoslo así."
- "Me parece."
- "Tiene sentido."
- "Entonces quedamos con eso."
- "Vamos por esa opción."

Estas expresiones deben analizarse dentro de su contexto.

Un "sí" aislado no debe considerarse automáticamente una decisión.

---

# 14. DECISIÓN POSTERIOR

Si una decisión inicial es modificada posteriormente durante la reunión, la decisión posterior válida reemplaza a la anterior.

Ejemplo:

Decisión inicial:

"Trabajaremos X."

Posteriormente:

"Después de lo conversado, mejor trabajemos Y."

Resultado:

Decisión final = Y.

El Skill debe registrar que Y reemplazó a X.

---

# 15. ÚLTIMA DECISIÓN VÁLIDA

La última decisión válida no significa simplemente la última frase de la reunión.

Es la última decisión que:

- no fue posteriormente rechazada;
- no fue posteriormente modificada;
- cuenta con aceptación o consenso suficiente;
- representa el cierre real de la discusión.

---

# 16. ESTADOS DEL OBJETIVO

El objetivo debe clasificarse como:

### MANTENIDO

El Comité decidió conservar el objetivo base.

Acción:

Mantener el objetivo del Monthly Content Planner.

### MODIFICADO

El Comité decidió cambiar el enfoque del objetivo base.

Acción:

Solicitar confirmación humana.

### REEMPLAZADO

El Comité decidió sustituir el objetivo base por otro enfoque para el mes.

Acción:

Solicitar confirmación humana.

### CONFIRMADO

Existe una decisión suficientemente clara y validada.

### NO DEFINIDO

No existe suficiente evidencia para determinar el objetivo final.

Acción:

No generar una Orden Estratégica Mensual confirmada.

---

# 17. NIVEL DE CONFIANZA

Toda decisión estratégica debe incluir:

- Alto;
- Medio;
- Bajo.

### ALTO

Existe una decisión clara y respaldada por el cierre de la conversación.

### MEDIO

La decisión parece clara, pero existe cierta ambigüedad.

### BAJO

Existen contradicciones o falta de evidencia suficiente.

Si el nivel es Bajo, no debe emitirse una Orden Estratégica Mensual confirmada.

---

# 18. DETECCIÓN DE UNA NUEVA ORDEN

El Skill debe comparar el resultado del Comité con el objetivo base del Monthly Content Planner.

Debe determinar:

### CASO 1: NO HAY CAMBIO

El Comité mantiene el objetivo base.

Resultado:

NO existe una nueva orden estratégica que modifique el objetivo.

El Monthly Content Planner mantiene su objetivo.

---

### CASO 2: EXISTE UNA NUEVA ORDEN

El Comité decide cambiar el enfoque del mes.

Resultado:

Existe una posible nueva Orden Estratégica Mensual.

El Skill debe solicitar confirmación humana.

---

### CASO 3: NO EXISTE UNA DECISIÓN CLARA

Hay discusión, pero no existe una conclusión suficientemente clara.

Resultado:

No se genera una orden confirmada.

El Monthly Content Planner mantiene su objetivo actual.

---

Cuando exista una nueva Orden Estratégica Mensual que modifique o reemplace el objetivo base, el Skill debe detenerse antes de generar una orden confirmada.

---

# 20. RESPUESTA DEL USUARIO: SÍ

Si el usuario confirma:

- registrar la confirmación;
- marcar la orden como CONFIRMADA;
- generar la Orden Estratégica Mensual;
- indicar que el Monthly Content Planner debe aplicar la nueva orden durante ese mes.

---

# 21. RESPUESTA DEL USUARIO: NO

Si el usuario responde negativamente:

- no generar la orden como confirmada;
- no modificar el Monthly Content Planner;
- mantener el objetivo base;
- solicitar aclaración si es necesario.

---

# 22. RESPUESTA DEL USUARIO CON CORRECCIÓN

Si el usuario responde indicando un objetivo diferente, debe considerarse la nueva información como una instrucción del usuario.

El Skill debe actualizar el análisis y presentar nuevamente la propuesta de Orden Estratégica Mensual antes de considerarla confirmada.

---

# 23. DURACIÓN DE LA ORDEN ESTRATÉGICA

Una Orden Estratégica Mensual pertenece al mes para el cual fue aprobada.

No debe convertirse automáticamente en una regla permanente.

Ejemplo:

Objetivo base:

"Gerentes y directores + mayor alcance."

Orden de septiembre:

"Priorizar el nuevo enfoque definido por el Comité."

Durante septiembre:

Se aplica la Orden Estratégica Mensual.

Para octubre:

El objetivo base vuelve a ser la referencia, salvo que el Comité genere y confirme una nueva Orden Estratégica Mensual.

---

# 24. PRIORIDAD DE LAS ÓRDENES

La jerarquía estratégica debe ser:

1. Orden Estratégica Mensual confirmada.
2. Objetivo base del Monthly Content Planner.
3. Ideas y sugerencias.
4. Temas pendientes.

Una Orden Estratégica Mensual confirmada tiene prioridad sobre el objetivo base únicamente durante el mes correspondiente.

---

- eventos;

# 37. REGLAS PERMANENTES

1. No confundir una idea con una decisión.
2. No confundir una opinión con un acuerdo.
3. No seleccionar automáticamente la primera propuesta.
4. No seleccionar automáticamente la última frase.
5. No seleccionar una propuesta por haber sido mencionada más veces.
6. No seleccionar una propuesta únicamente por quién la propuso.
7. Analizar la discusión completa cuando exista desacuerdo.
8. Detectar aceptación.
9. Detectar concesión.
10. Detectar consenso.
11. Detectar cambios de opinión.
12. Detectar decisiones posteriores que reemplazan decisiones anteriores.
13. Identificar la última decisión válida.
14. Utilizar la reunión completa de Granola cuando sea necesario.
15. Utilizar Miro como fuente complementaria.
16. Señalar contradicciones entre fuentes.
17. No inventar decisiones.
18. No inventar objetivos.
19. No inventar responsables.
20. No inventar fechas.
21. No inventar materiales.
22. No convertir sugerencias en órdenes.
23. No convertir temas pendientes en decisiones.
24. No modificar automáticamente el objetivo base del Monthly Content Planner.
25. Generar una nueva Orden Estratégica Mensual cuando exista un cambio confirmado.
26. Solicitar confirmación humana antes de confirmar una nueva Orden Estratégica Mensual.
27. No modificar el Monthly Content Planner si la nueva orden no fue confirmada.
28. Una Orden Estratégica Mensual confirmada tiene prioridad sobre el objetivo base únicamente durante el mes correspondiente.
29. Una Orden Estratégica Mensual no elimina permanentemente el objetivo base.
30. Para un nuevo mes, el objetivo base vuelve a ser la referencia salvo que exista una nueva Orden Estratégica Mensual confirmada.
31. No modificar automáticamente la frecuencia permanente del Monthly Content Planner.
32. Mantener separadas las funciones del Comité, Planificador y Creación de Contenido.
33. Entregar una instrucción estructurada para el Monthly Content Planner.
34. Si existe incertidumbre relevante, detener el proceso y solicitar confirmación.
35. La confirmación humana constituye el último control antes de emitir una nueva Orden Estratégica Mensual confirmada.

# 38. PRINCIPIO CENTRAL

Este Skill debe responder con precisión:

**¿Qué decidió realmente el Comité de Marketing para este mes?**

Y posteriormente:

**¿Esa decisión constituye una nueva Orden Estratégica Mensual que debe cambiar temporalmente la planificación del Monthly Content Planner?**

El proceso debe ser:

ANALIZAR
→ INTERPRETAR
→ RESOLVER DISCUSIONES
→ IDENTIFICAR DECISIÓN FINAL
→ COMPARAR CON OBJETIVO BASE
→ DETECTAR NUEVA ORDEN
→ SOLICITAR CONFIRMACIÓN HUMANA
→ CONFIRMAR
→ ENTREGAR ORDEN AL MONTHLY CONTENT PLANNER

Nunca debe saltarse la confirmación humana cuando exista un cambio estratégico relevante.
